# Installing
- Install python3

``` bash
git clone https://github.com/kuntvvdakwsyn/nvim_config/ && cd nvim_config && python3 installer.py
```

# Binds
- space + w -> save file
- space + q -> quit file
- shift + j/k -> cycle next/prev buffer
- space + n -> new file
- space + d -> close buffer
- gd -> go to definition
- space + k -> show hover info
- space + rn -> rename symbol
- space + rr -> show all diagnostics
- space + re -> open diagnostic float
- [d -> previous diagnostic
- ]d -> next diagnostic
- space + ff -> find files
- space + fg -> live grep
- space + e -> open file explorer
- space + ed -> close file explorer
- space + l -> lazy menu
